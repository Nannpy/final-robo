## การติดตั้งฮาร์ดแวร์

ติด IR สองตัวด้านข้างฝั่งเดียวกัน ตัวหนึ่งค่อนไปทางหัว อีกตัวค่อนไปทางท้าย
วัดระยะห่างระหว่างสองตัวจริง ๆ แล้วใส่ลง `IR_BASELINE_CM` ใน `config.py`
เพราะค่านี้ใช้คำนวณมุมเอียงเทียบกำแพง

ToF ด้านหน้าเป็นตัวที่ติดมากับหุ่น อ่านผ่าน `ep_robot.sensor.sub_distance`

## ข้อจำกัดของ SDK ที่ติดตั้งอยู่

SDK ใน venv (0.1.1.x) ยังไม่มี `sensor_adaptor.sub_adapter()` ซึ่งเป็น stream
ที่ push ค่า ADC ทุกช่องพร้อมกันได้ถึง 50 Hz โค้ดจึงถอยไปใช้ `get_adc()`
ถามทีละช่อง ซึ่งได้อัตราจริงราว 8-10 Hz

ผลที่ตามมา: ตัวคุมทำงานบนข้อมูลที่ช้ากว่า control loop จึงต้องระวังไม่ตั้ง kp สูง
ถ้าอยากได้ 20 Hz เต็ม ให้ติดตั้ง SDK จาก source ในโฟลเดอร์นี้แทน

```bash
pip install -e .
```

รันจาก root ของ RoboMaster-SDK แล้ว `ir_sensor.py` จะสลับไปใช้ stream ให้เอง
(มีการตรวจและถอยกลับอัตโนมัติอยู่แล้ว) แนะนำให้ทำหลังผ่าน checkpoint ไปก่อน
ไม่ใช่ระหว่างวันสอบ

## ตรวจว่า IR เสียบพอร์ตไหนจริง

ถ้าค่าที่อ่านได้ค้างนิ่งทั้งที่ขยับหุ่น ให้ไล่สแกนทุกช่องก่อน
พอร์ตที่ไม่มีอะไรเสียบมักคืนค่าคงที่ค่าหนึ่ง ซึ่งดูเผิน ๆ เหมือนค่าที่ใช้ได้

```bash
python aj_sahapong/lab5/scan_ports.py
```

รอบแรกเปิดโล่ง รอบสองเอามือบัง ช่องที่ค่าต่างกันมากคือช่องที่มี IR อยู่จริง
โปรแกรมพิมพ์บรรทัด `IR_FRONT` / `IR_REAR` ให้คัดลอกไปวางใน `config.py`

## ทางลัด: ลงสนามก่อน ค่อยจูนทีหลัง

ถ้าอยากรันเลยโดยไม่รอสอบเทียบ ใช้ `field_run.py` ตัวเดียวจบ

```bash
python aj_sahapong/lab5/field_run.py
```

ทำงานสามขั้น
1. วางหุ่นขนานกำแพงที่ระยะเป้าหมาย กด Enter เพื่อจำค่า ADC เป็นจุดสมดุล
   (คุมบน ADC ดิบ ไม่ต้องมีสมการสอบเทียบ)
2. หุ่นขยับเล็กน้อยเพื่อหาเครื่องหมายของแกน y และ z เอง ไม่ต้องเดา
3. วิ่งจริง หยุดอัตโนมัติเมื่อ ToF ด้านหน้าใกล้กว่า `STOP_FRONT_CM`

จูนสดระหว่างวิ่งโดยพิมพ์ในเทอร์มินัลแล้วกด Enter

| คำสั่ง | ผล |
|--------|-----|
| `d 0.002` | kp ของการคุมระยะ (แกว่งซ้ายขวา = ลด, เข้าเป้าช้า = เพิ่ม) |
| `D 0.0002` | kd ของการคุมระยะ |
| `I 0.0008` | ki ของการคุมระยะ ใช้แก้ระยะที่ค้างตอนกำแพงเฉียง |
| `a 0.3` | kp ของการคุมมุม (หัวส่าย = ลดตัวนี้ก่อนเป็นอันดับแรก) |
| `A 0.03` | kd ของการคุมมุม |
| `i 0` | ki ของการคุมมุม ปกติไม่ต้องใช้ |
| `f 0.2` | ตัวกรองพจน์ D ยิ่งน้อยยิ่งกรองหนัก |
| `v 0.15` | ความเร็วเดินหน้า m/s |
| `p` | หยุดชั่วคราว / วิ่งต่อ |
| `r` | ล้างค่าสะสมของ PID |
| `w` | บันทึกค่าที่จูนไว้ ครั้งหน้าโหลดให้อัตโนมัติ |
| `q` | จบการทำงาน |

### แก้อาการหัวส่าย

ไล่ตามลำดับนี้ อย่าข้ามไปเพิ่ม kd ก่อน

1. **ลด `a`** ครั้งละครึ่ง จนหัวนิ่ง แล้วค่อยไต่ขึ้นทีละ 20 เปอร์เซ็นต์
   ตัวคุมมุมไวกว่าตัวคุมระยะมาก จึงเป็นตัวที่แกว่งก่อนเสมอ
2. **ลด `v`** ยิ่งเร็วยิ่งต้องแก้แรง อาการแกว่งยิ่งโต
3. **เพิ่ม `A` ทีละน้อย** (0.03 → 0.05 → 0.08) ถ้าเพิ่มแล้วกระตุกขึ้น
   ให้ลด `f` ลงเป็น 0.1 เพื่อกรองหนักขึ้น แล้วลองใหม่
4. ระยะค้างไม่เข้าเป้าตอนกำแพงเฉียง ค่อยเปิด `I 0.0008`

ทำไมต้องเรียงแบบนี้: จากล็อกจริง IR อัปเดตราว 8-10 Hz ขณะ control loop
วิ่ง 20 Hz ระบบจึงมีดีเลย์ในตัวราวหนึ่งร้อยมิลลิวินาที ดีเลย์ทำให้ kp สูง
กลายเป็นการแกว่งทันที ส่วนพจน์ D บนสัญญาณที่มี noise ช่วยได้จำกัดและ
ถ้าไม่กรองจะยิ่งทำให้กระตุก ลด kp กับลดดีเลย์จึงได้ผลกว่าเพิ่ม kd มาก

### กันหุ่นหนี

`field_run.py` จะหยุดเองเมื่อเจอสามอย่างนี้
- ตอนทดสอบแกน ถ้า IR ตัวใดค่าเปลี่ยนน้อยกว่า 15 adc แปลว่าตัวนั้นไม่ได้ส่องกำแพง
  หยุดทันทีพร้อมบอกให้ไปรัน `scan_ports.py`
- ระหว่างวิ่ง ถ้าค่า IR ค้างนิ่งเกิน 2.5 วินาที = สายหลุดหรือพอร์ตผิด
- ถ้าสั่งความเร็วชนเพดานติดต่อกันเกิน 1.2 วินาที = ระบบแกว่งคุมไม่อยู่

`wall_follow.py` ด้านล่างเป็นเวอร์ชันที่คุมเป็นเซนติเมตรจริง ใช้ตอนทำรายงาน
หลังสอบเทียบแล้ว

## หลักการควบคุม

IR สองตัวให้ข้อมูลสองอย่างพร้อมกัน จึงแยกเป็น PID สองตัวที่ไม่รบกวนกัน

- ระยะห่างกำแพง = ค่าเฉลี่ยของ IR หน้าและหลัง → PID → ความเร็วด้านข้าง `y`
- มุมเอียงเทียบกำแพง = `atan2(หน้า - หลัง, baseline)` → PID → ความเร็วหมุน `z`

ทำแบบนี้ได้เพราะหุ่นเป็นล้อ mecanum จึงสไลด์เข้าออกจากกำแพงได้โดยไม่ต้องหมุนตัว

## ข้อจำกัดที่ควรรู้

- Sharp IR วัดได้ราว 10-80 ซม. ที่ระยะใกล้กว่านั้นเส้นโค้งจะย้อนกลับ
  โค้ดจึงตัดค่านอกช่วง `IR_MIN_VALID_CM`-`IR_MAX_VALID_CM` ทิ้งเป็น `None`
- baseline สั้น (~13.5 ซม.) ทำให้มุมที่คำนวณได้ไวต่อ noise
  ผลต่าง 10 มม. คิดเป็นมุม 4.2 องศา จึงกรองด้วยค่ามัธยฐานก่อนใช้เสมอ
- ถ้าหุ่นแกว่งซ้ายขวาให้ลด `kp` ของ `PID_DISTANCE`
  ถ้าเข้าเป้าช้าเกินให้เพิ่มทีละ 20 เปอร์เซ็นต์
